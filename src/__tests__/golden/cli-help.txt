=== agent-chat
Usage: agent-chat [options] [command]

cross-session messaging for Claude Code

Options:
  -V, --version              output the version number
  -h, --help                 display help for command

Human commands:
  inbox                      what your agents need from you
  answer <id> <text...>      answer a question; routes back to the asker
  dismiss <id>               close an item without answering, or decline an endorsement
  approve <id> <allow|deny>  answer an agent's permission prompt from here
  endorse <id>               approve a composed message; delivers it with your authority

Commands:
  service                    run and inspect the broker daemon
  debug                      diagnostics: sessions, history, routing
  doctor                     check the things that fail silently
  lifecycle                  offline maintenance of the agent lifecycle ledger
  help [command]             display help for command

Agent commands:
  watch [options] <name>     stream messages for a session that cannot receive channel pushes
  agent                      durable agents
  teleport                   teleport control
  profiles                   agent profiles available to spawn with

=== agent-chat service
Usage: agent-chat service [options] [command]

run and inspect the broker daemon

Options:
  -h, --help         display help for command

Commands:
  start [options]    start the broker, detached by default
  stop [options]     SIGTERM the broker, then SIGKILL if it lingers; refuses while an agent is
                     mid-spawn or an ask is unanswered
  status [options]   socket, pid file and /health, reported separately
  restart [options]  stop then start, reusing the port from broker.meta.json; refuses while an agent
                     is mid-spawn or an ask is unanswered
  logs [options]     tail the broker log; no --follow, by design
  open [options]     open the dashboard, or print its URL when not a TTY
  help [command]     display help for command

=== agent-chat service start
Usage: agent-chat service start [options]

start the broker, detached by default

Options:
  -p, --port <port>  HTTP port to bind
  -f, --foreground   run in this terminal instead of detaching
  -h, --help         display help for command

=== agent-chat lifecycle
Usage: agent-chat lifecycle [options] [command]

offline maintenance of the agent lifecycle ledger

Options:
  -h, --help          display help for command

Commands:
  backfill [options]  write a ledger row for every non-retired spawned agent that has none; refuses
                      while a broker runs
  help [command]      display help for command

=== agent-chat lifecycle backfill
Usage: agent-chat lifecycle backfill [options]

write a ledger row for every non-retired spawned agent that has none; refuses while a broker runs

Options:
  --dry-run       print one line per agent that would get a row, and write nothing
  --since <days>  only agents with an event in the last <days> days
  -h, --help      display help for command

=== agent-chat watch
Usage: agent-chat watch [options] <name>

stream messages for a session that cannot receive channel pushes

Options:
  --since <id|now|all>  start from a log id, the current head, or the whole backlog (default: "now")
  --interval <seconds>  how often to poll (default: "2")
  --once                print what is waiting and exit, instead of following
  -h, --help            display help for command

=== agent-chat agent
Usage: agent-chat agent [options] [command]

durable agents

Options:
  -h, --help                                   display help for command

Commands:
  ls                                           agents, with lifecycle and presence
  spawn [options] <name> <profile> [brief...]  start a new agent
  retire [options] <name>                      release isolation, end the process, and free the name
  resume [options] <name>                      bring a stopped agent back on its own conversation
                                               (headless by default)
  worktrees [options]                          worktrees agent-chat is holding, and which nobody is
                                               using
  surface <name>                               bring a headless agent into a window you can answer
  budget [name]                                context fill and account rate limits, per agent
  help [command]                               display help for command

=== agent-chat agent spawn
Usage: agent-chat agent spawn [options] <name> <profile> [brief...]

start a new agent

Options:
  --briefing <slug|auto>  prepend an active-work initiative's orientation to the brief
  --brief-stdin           read the brief from stdin, keeping it out of world-readable argv
  --config-dir <path>     the Claude config dir, and therefore the account, to run it on
  -h, --help              display help for command

=== agent-chat agent retire
Usage: agent-chat agent retire [options] <name>

release isolation, end the process, and free the name

Options:
  --force     discard uncommitted or unmerged work the isolation is holding
  -h, --help  display help for command

=== agent-chat agent resume
Usage: agent-chat agent resume [options] <name>

bring a stopped agent back on its own conversation (headless by default)

Options:
  --message <value>  the turn it resumes on
  --surface <value>  where it comes back: headless, iterm-pane, iterm-tab, iterm-window
  -h, --help         display help for command
